# v1.4.0-rc.1 - Stable Candidate Build

## Summary

This release candidate promotes the v1.4.0 beta line into stable validation. It includes the localized Rushes Log export work, compact Chinese PDF output, macOS notarized distribution, Windows beta11 metadata follow-up, and website fallback wiring needed before the final v1.4.0 stable release.

Use this RC for final real-device validation before publishing v1.4.0 stable.

## Changes

- Changed the default prerelease build suffix from `beta.11` to `rc.1`.
- Kept the base app version at `1.4.0` across package, Cargo, and Tauri config files.
- Carries forward localized Rushes Log PDF, CSV, TSV, Excel, and clipboard TSV exports.
- Carries forward compact Chinese Rushes Log PDF output and Windows-safe PDF overwrite handling.
- Carries forward beta11 macOS and Windows download metadata behavior.
