# v1.4.0-beta.11 - Compact Report PDF Build

## Summary

This beta republishes the report export work with the PDF size fix included in the signed macOS build. Chinese Rushes Log PDF exports now keep localized labels while avoiding the oversized full-font embedding seen in beta10.

## Changes

- Reduced Chinese Rushes Log PDF output size by deduplicating embedded font streams, pruning unused PDF objects, compressing PDF streams, and only loading the CJK font where it is needed.
- Added Windows-aware temporary PDF replacement so report optimization can safely replace an existing export path on Windows.
- Added Windows CJK font fallback candidates for future Windows report exports.
- Kept localized Rushes Log PDF, CSV, TSV, Excel, and clipboard TSV report fields from beta10.
- Updated beta-channel build metadata to `v1.4.0-beta.11`.
- Rebuilt the macOS beta DMG from current `main`.
