# v1.4.0-beta.10 - Localized Report Export Build

## Summary

This beta turns the report template work into the real Rushes Log export path. Exported reports now follow the current DIT Pro app language and include the source/destination and media breakdown fields needed for offload handoff review.

## Changes

- Localized Rushes Log PDF, CSV, TSV, Excel, and clipboard TSV exports using the current app language.
- Added report fields for source path, destination paths, total file count, completed/failed file count, video/audio/image/other file counts, media type sizes, and source release status.
- Added Chinese-capable PDF font fallback for macOS so Chinese report labels render correctly.
- Fixed beta update comparison so `beta.7` is not treated as newer than `beta.10`.
- Fixed Rushes Log save panel titles so PDF/CSV/TSV/Excel exports show the correct action name.
- Updated beta-channel build metadata to `v1.4.0-beta.10`.
- Signed, notarized, stapled, and Gatekeeper-validated the macOS beta10 DMG with `Developer ID Application: Negdims Inc. (7C3KJRTUK9)`.
- Updated beta website download fallback and `website/software/latest-beta.json`.

- `npm run build`
- `cargo fmt --all --check`
- `cargo check -p dit-pro`

## Known Issues

- TC207/TC209/TC212 remain pending before stable validation.
- Cloud upload remains experimental until the persistent cloud queue milestone.
- Chinese PDF export is functional, but current genpdf output embeds the full fallback CJK font and can produce large PDFs. Fixing this properly requires font subsetting or a Quartz/system-print PDF path before stable.
- Native macOS select menus and notification banners still require manual confirmation in several Computer Use-limited tests.
