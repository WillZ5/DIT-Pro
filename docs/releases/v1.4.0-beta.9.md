# v1.4.0-beta.9 - Proxy and Cloud Resilience Build

## Summary

This beta focuses on clearing the remaining beta8 reliability issues that blocked stable validation: proxy generation on the current macOS ffmpeg build, cloud upload failure cleanup, reset-settings confirmation behavior, resume regression coverage, and Developer ID distribution readiness.

## Changes

- Fixed proxy generation when ffmpeg does not include the `drawtext` filter by falling back to proxy output without burned-in timecode.
- Fixed proxy generation for camera MOV files that include timecode/data streams by mapping only the primary video stream and optional audio streams.
- Fixed reset-to-default settings confirmation so canceling the dialog cannot mutate visible settings state.
- Improved cloud upload failure handling so finalize/stat failures clean up partial remote files and surface warnings without blocking completed local copies.
- Confirmed resume handling allows terminal active cards to recover in the same UI session and added regression coverage that resume copies only pending tasks.
- Signed, notarized, stapled, and Gatekeeper-validated the macOS beta9 DMG with `Developer ID Application: Negdims Inc. (7C3KJRTUK9)`.
- Updated beta-channel update metadata for `v1.4.0-beta.9`.
