# v1.4.0-beta.8 - Reliability Fix Build

## Summary

This beta focuses on real-device reliability issues found during the v1.4.0 test pass.

## Changes

- Fixed multi-destination copy isolation so one broken target does not fail every destination.
- Blocked empty source folders before a workflow is registered.
- Added source path revalidation after copy completion to catch source deletion or rename during POSIX open-handle copies.
- Added cloud upload chunk timeouts, partial upload cleanup, and remote size verification for experimental WebDAV/S3 sync.
- Fixed same-session recovery from terminal active cards.
- Prevented Terminate All from changing completed historical jobs in the UI.
- Fixed FFmpeg drawtext escaping for proxy timecode burn-in.
- Added beta-channel update detection through `latest-beta.json`.
